# Bus Route Planning Simulation

The Morphy City Transit Authority is planning to introduce an network of bus
routes to serve the city. This software system is designed to simulate
possible bus routes and provide a way to evaluate the efficiency and
effectiveness of the proposed routes.

## Usage

Run the simulation with the following command:

```bash
$ npm install
$ npm start
```

### Running Unit Tests

Run the unit tests with the following command:

```bash
$ npm test
```
